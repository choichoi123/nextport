# 메인·전체 프로젝트·미리보기

승인된 예시 디자인을 실제 메인과 전체 프로젝트 화면에 적용했습니다. 실행·검증·공개 배포의 현재 사실은 [현재 상태](CURRENT_STATE.md)에서 관리합니다.

## 화면 경로

| 경로 | 역할 |
| --- | --- |
| `/` | 개발자 소개·대표작 최대 3개·하는 일·연락 |
| `/projects` | 실제 전체 목록·검색·분야 필터·최근 시작 순/이름순 정렬 |
| `/archive` | 이전 홈과 Lottie 보관본. 메인에서 분리하고 검색엔진 수집 제외 |
| `/preview` | 같은 공통 디자인의 확인용 경로. 검색엔진 수집 제외, 무설정에서만 예시 표시 |

기존 메인을 주석 묶음으로 남기는 대신 `pages/archive.js`에 실행 가능한 보관본으로 옮겼습니다. 주소를 직접 열거나 미리보기의 ‘기존 홈과 비교하기’로 접근할 수 있고, 보관본에서 현재 메인으로 돌아올 수 있습니다.

## 로컬 실행과 확인

원본 저장소의 실행 방법은 [README](../README.md)를 따릅니다. 평소 로컬 Notion 설정은 비워 두며, 사용자 승인으로 연결한 실데이터 검증 사본은 원본 저장소와 환경파일을 분리합니다. 현재 실행 주소·사본 경로·동기화한 소스는 현재 상태를 기준으로 합니다.

검증용 사본은 원본 저장소의 파일 편집을 자동으로 따라가지 않습니다. 파일을 수정하면 필요한 소스만 사본에 반영하고 화면을 새로고침합니다. 환경파일·인증값·다른 서버의 빌드 산출물을 복사하지 않습니다. 기존 브라우저와 사용자가 유지하도록 요청한 작업 탭은 종료하지 않습니다.

## 데이터 처리

- `/`·`/projects`는 `loadPortfolioProjects`에서 실제 Notion 목록만 받습니다. 무설정은 빈 목록이며 파주 등 예시로 보충하지 않습니다.
- `/preview`의 `loadPortfolioPreview`는 세 연결 설정이 모두 비어 있을 때만 예시 3개를 사용합니다. ‘예시 콘텐츠’와 구성 스케치 구분을 표시합니다.
- 실제 설정의 인증·설정·통신 오류는 그대로 전달하며 예시나 정상 빈 목록으로 숨기지 않습니다. 실제 DB의 빈 응답도 보존합니다.
- 카드 제목·설명·월 단위 기간·태그·표지·상세/GitHub/YouTube 링크는 기존 Notion 계약을 따릅니다. 토큰이나 원본 응답 전체를 클라이언트에 넘기지 않습니다.
- 메인의 대표작은 **부산 WISEOP → 파주 바우처 → 이케이시스 홈페이지** 순으로 확인된 개인 DB 페이지 ID를 우선합니다. 없는 항목은 조회 목록 순서로 채워 최대 3개를 표시합니다. 프로젝트 내용은 원문을 재사용합니다.
- 전체 목록은 확인된 시작 월의 내림차순을 기본으로 하며, 시작 월 미정인 항목은 뒤에 둡니다. 검색·필터·정렬은 클라이언트 표시 순서만 바꾸고 DB를 쓰지 않습니다.
- 실제 역할·핵심 기여를 원문에서 확인할 수 없으면 상세 확인 안내를 표시합니다. 일반 소개를 개인 성과로 바꾸지 않습니다.

표지는 이미지 전체가 보이도록 비율 1.6과 `contain`을 사용합니다. 본문에 올린 화면은 자동으로 커버가 되지 않으며, 커버 URL 누락·실패는 별도 구성 스케치로 대체합니다. API 읽기 허용과 방문자의 Notion 상세 페이지 접근 권한도 구분합니다.

## 공통 화면

- `PortfolioShell`: 사이트 제목·검색 메타·주요 메뉴·테마·푸터. 기존 사이트 확인 메타와 방문 측정은 표준 화면에서 유지하고 미리보기에는 수집 제외 메타를 둡니다.
- `PortfolioHome`: 소개·대표작·역량 설명·기존 공개 연락 링크. 메인에는 미리보기 표시를 붙이지 않습니다.
- `ProjectCard`: 메인·목록의 공통 표지·기간·태그·역할·실제 자료 링크. 예시 모달은 미리보기에서만 동작합니다.
- 전체 목록: 검색어와 분야를 함께 적용하고, 결과 개수·빈 결과·초기화를 제공합니다. 여러 검색어는 모두 포함하는 항목을 찾습니다.

## 주요 파일

| 경로 | 역할 |
| --- | --- |
| `pages/index.js`, `pages/projects.js` | 공개 홈·전체 목록과 실제 데이터의 정적 생성·ISR |
| `pages/archive.js`, `pages/preview.js` | 이전 홈 보관·예시 미리보기 |
| `components/portfolio/` | Shell·홈·카드·공유 아이콘 |
| `components/preview/project-art.js` | 실제 표지와 구분한 구성 스케치·로드 실패 처리 |
| `styles/portfolio-preview.module.css` | 메인·전체 목록·미리보기의 공유 디자인 |
| `styles/portfolio-catalog.module.css` | 전체 목록의 검색·필터·빈 상태 |
| `lib/portfolio-preview.mjs` | 실제/예시 로더와 안전한 표시 필드·대표작 선정 |
| `lib/portfolio-catalog.mjs` | 검색·분야·정렬 |
| `tests/portfolio-preview.test.mjs`, `tests/portfolio-catalog.test.mjs` | 데이터 경계·샘플 노출 방지·대표작·검색·정렬 검사 |

로컬 메인 변경은 공개 배포 완료를 의미하지 않습니다. Notion 읽기 연결·DB 공개 범위·배포 환경 변경은 별도의 요청 범위를 따릅니다.
