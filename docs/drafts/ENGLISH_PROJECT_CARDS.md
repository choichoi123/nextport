# 영문 프로젝트 카드 번역안

기준일: **2026-11-12 KST**. 공식 Notion 연결에서 현재 관리본의 프로젝트 7개를 읽고 한국어 제목·카드 설명에 맞춰 작성한 검토 확정본입니다. 영문 카드 문구만 적용하며 한국어 상세 본문은 이번 범위에 포함하지 않습니다.

**현재 상태:** 2026-11-12 Notion 영문 카드 문구 반영 및 공식 재조회 대조 완료. 영문 제목·설명 7개와 명시적 개인 역할 2개를 저장했고, 나머지 역할 5개는 빈 값으로 유지했습니다. 기존 속성·표지 참조·아이콘·한국어 본문의 fetch 텍스트는 변경 전후 일치했습니다. 실제 화면 검증은 별도입니다.

## 적용 범위

- 영문 제목·설명·역할은 각각 `NameEn`·`DescriptionEn`·`RoleEn`에 적용합니다. 기존 한국어 필드를 덮어쓰지 않습니다.
- 개인 역할은 현재 `Description`에 본인의 담당 문장이 있는 부산 WISEOP·파주에만 번역합니다. 나머지 5개는 `RoleEn`을 빈 값으로 유지하며, 개인 기여가 없다는 뜻은 아닙니다.
- 기간·기술 태그·표지·프로젝트 상세 링크·정렬·권한과 한국어 상세 본문은 유지합니다. 새로운 성과·기여 범위·참여 인원을 추가하지 않습니다.
- `교통약자 이동지원`은 **accessible mobility services**, 관제는 **operations**, 재배치는 **repositioning**, 체계공학은 **systems engineering**으로 옮깁니다. 운영 배포나 실시간 기능을 추가로 주장하지 않습니다.
- 목록 순서는 비교를 위한 편집 순서입니다. Notion의 원래 순서와 사이트의 정렬을 변경하는 지시가 아닙니다.

## 검토 사항

- SaaS의 현재 한국어 설명에는 HTML 문단 표기가 포함돼 있습니다. 비교 문서에서는 줄 끝 공백만 정리했고, 실제 한국어 원문은 보존합니다. 영문 설명은 일반 문장으로 작성했습니다.
- 부산·SE-LAB·EpAI 제목은 검토 과정에서 카드 가독성을 위해 핵심 명칭으로 정리했습니다. 기존 설명에 담긴 기능과 본인 역할은 유지합니다. 이케이시스는 설명 원문의 리뉴얼 의미를 제목에도 반영했습니다.
- 영문 상세 본문은 이번 범위에 포함하지 않습니다. 영문 카드의 상세 링크도 기존 한국어 Notion 페이지를 가리킵니다.
- 제목·설명이 긴 카드는 모바일에서 줄바꿈·높이와 읽기 흐름을 확인합니다. 화면에 맞추려다 의미를 축소하거나 본인 기여를 추가하지 않습니다.
