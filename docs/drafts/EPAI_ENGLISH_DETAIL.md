## Overview

Epidemic-AI (EpAI) is an infectious disease forecasting-system project combining integrated epidemiological modeling with AI. The project aims to predict the spread of infectious diseases more accurately.

**Period:** 2020-07-23–2022-07-22

## Project Materials

The original project materials include an EpAI interface and machine-learning data. The images are preserved with English captions; their original content has not been recreated.

**Image 01.** EpAI interface.

**Image 02.** Machine-learning data shown in the EpAI project materials.

## Data Collection and Preparation

Data was collected through APIs from Korea's Public Data Portal and sources such as [Our World in Data](https://ourworldindata.org/). The preparation work included cleaning the collected data and converting it into CSV files for machine-learning use.

## Technologies

Python, JavaScript, React, Node.js, Express, MongoDB, Google Cloud Platform (GCP), and Bayesian networks are listed in the project materials.
